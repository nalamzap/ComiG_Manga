# ComiG Manga

ComiG Manga is a modern, lightweight, and feature-rich Manga and Comic reader for Android, built with Jetpack Compose and Material 3.

## 🚀 Features

- **Multi-Format Support**: Import and read `.cbz`, `.zip`, `.pdf`, and local image folders.
- **Smart Library**: 
  - Automatically groups volumes into series.
  - Organize your collection by genres.
  - Powerful search and filtering options.
- **Optimized Reading Experience**:
  - Double-tap to zoom and pan for detailed artwork.
  - Supports multiple reading directions (Horizontal RTL, Vertical).
  - Progress tracking: never lose your place in a volume.
- **Modern UI**: Clean, intuitive interface with Material 3 design and dynamic theming support.
- **Local First**: Your data stays on your device.

## 🛠 Tech Stack

- **UI**: [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **Architecture**: MVVM with Clean Architecture principles.
- **Database**: [Room](https://developer.android.com/training/data-storage/room) for local storage.
- **Image Loading**: [Coil](https://coil-kt.github.io/coil/) for efficient image processing.
- **Navigation**: Navigation Compose.
- **Language**: 100% Kotlin.

## 📦 Getting Started

### Prerequisites
- Android Studio Ladybug or newer.
- Android SDK 26+ (Android 8.0).

### Installation
1. Clone the repository.
2. Open the project in Android Studio.
3. Sync Gradle and run the `:app` module.
